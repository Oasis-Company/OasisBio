"Continue with Oasis" 宣传计划
Part 1 — 开发者落地页 /developer
目标： 让开发者在 30 秒内理解这是什么、能做什么、怎么开始。

页面结构：

Hero
  标题：  "Let your users sign in with their Oasis identity"
  副标题：一句话说明价值
  CTA：   [Get Started] → /developer/apps/new
          [Read the Docs] → /developer/docs

Button Preview（视觉展示）
  黑色背景上展示标准 "Continue with Oasis" 按钮样式
  旁边放可复制的 HTML 代码片段

三步接入
  1. Register your app → 获取 client_id
  2. Add the button → 复制代码片段
  3. Access user data → 展示可获取的数据类型

Scopes 展示
  5 个 scope 的卡片，每个说明能访问什么数据

底部 CTA
  [Start Building] → /developer/apps/new
Part 2 — 标准按钮组件 + 代码片段
目标： 开发者复制一段代码就能在自己的网站上放出按钮。

提供三种格式：

HTML（纯静态）
React/Next.js
带完整 PKCE 流程的 JavaScript
按钮样式：黑底白字，左侧 Oasis logo，文字 "Continue with Oasis"，和 Google/GitHub 按钮风格一致。

Part 3 — 主导航入口
目标： 让现有用户和访客都能发现这个功能。

Navbar 加 "Developers" 链接 → /developer
主页（如果有）加 "For Developers" section
页脚 Developers 列已有，确保链接正确
