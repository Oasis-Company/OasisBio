## R2 存储配置（已创建 bucket，待填写凭证）

从 Cloudflare 控制台获取以下信息，填入 `.env` 和 Cloudflare Pages 环境变量：

1. `CLOUDFLARE_R2_BUCKET_NAME` — 你创建的 bucket 名称
2. `CLOUDFLARE_R2_ACCOUNT_ID` — Cloudflare 账户首页右侧边栏的 Account ID
3. `CLOUDFLARE_R2_ACCESS_KEY_ID` — R2 → Manage R2 API Tokens → Create API Token → Access Key ID
4. `CLOUDFLARE_R2_SECRET_ACCESS_KEY` — 同上 → Secret Access Key
5. `CLOUDFLARE_R2_ENDPOINT` — 格式：`https://<Account_ID>.r2.cloudflarestorage.com`

创建 API Token 时权限选 **Object Read & Write**，绑定到对应 bucket。

填好后：
- 更新本地 `.env`
- 在 Cloudflare Pages 控制台添加这 5 个变量
- 触发重新部署
