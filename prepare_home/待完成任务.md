### 2. R2 存储配置

从 Cloudflare 控制台获取以下信息，填入 `.env` 和 Cloudflare Pages 环境变量：

| 变量 | 来源 |
|------|------|
| `CLOUDFLARE_R2_BUCKET_NAME` | R2 控制台 → 你的 bucket 名称 |
| `CLOUDFLARE_R2_ACCOUNT_ID` | Cloudflare 首页右侧 → Account ID |
| `CLOUDFLARE_R2_ACCESS_KEY_ID` | R2 → Manage R2 API Tokens → Create API Token |
| `CLOUDFLARE_R2_SECRET_ACCESS_KEY` | 同上（创建时显示一次） |
| `CLOUDFLARE_R2_ENDPOINT` | `https://<Account_ID>.r2.cloudflarestorage.com` |

创建 API Token 时权限选 **Object Read & Write**，绑定到对应 bucket。

填好后：
- 更新本地 `.env`
- 在 Cloudflare Pages 控制台添加这 5 个变量
- 触发重新部署

### 3. OAUTH_JWT_SECRET 配置

用于签名 OAuth access token 的密钥，**一旦设置不要更改**（改了会导致所有已颁发 token 立即失效）。

生成方式：
```bash
node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"
```

需要添加到：
1. 本地 `.env`：`OAUTH_JWT_SECRET=生成的64位hex字符串`
2. Cloudflare Pages 环境变量（Settings → Environment variables）
