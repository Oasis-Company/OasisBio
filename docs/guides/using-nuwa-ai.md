# Using Nuwa AI

Nuwa is OasisBio's AI assistant that analyzes your characters and generates cognitive framework suggestions to make them more realistic and consistent.

## What Nuwa Does

Nuwa uses a **cognitive framework distillation methodology** to:

- Generate **Mental Models**: How your character thinks
- Create **Decision Heuristics**: Rules your character follows
- Define **Expression DNA**: How your character communicates
- Suggest **Abilities**: Skills based on character context
- Propose **Eras**: Time periods that fit the narrative
- Design **Worlds**: Fictional universes for your character

## How to Use Nuwa

### Step 1: Prepare Your Character

Before running Nuwa, ensure your character has:

- Basic information (name, tagline, description)
- At least one era
- Some abilities or world references

### Step 2: Configure the Analysis

In the Nuwa tab, choose:

- **Mode**: Quick (fast) or Deep (thorough)
- **Scope**: Select which aspects to analyze
  - Description
  - Abilities
  - Eras
  - Worlds
  - References
  - DCOS Analysis
- **Source Policy**: Local only or local + web enrichment

### Step 3: Run the Analysis

Click **"Run Distillation"** and wait for processing.

### Step 4: Review Suggestions

Each suggestion includes:

- **What it means**: Plain language explanation
- **Recommended action**: Specific steps to take
- **Consistency score**: How well it fits your character (0-100%)

### Step 5: Accept or Reject

- **Accept**: Apply the suggestion to your character
- **Reject**: Discard the suggestion
- **Accept All** / **Reject All**: Batch processing

## Understanding the Output

### Mental Models

Mental models describe how your character processes information:

```
Example: "Risk-Averse Optimizer"
- Thinks before acting
- Weighs consequences heavily
- Seeks win-win solutions
- Avoids irreversible decisions
```

### Decision Heuristics

Decision heuristics are rules your character follows:

```
Example: "Minimum Harm Principle"
"If forced to choose between bad options,
select the one causing least overall damage,
even if it personally costs more."
```

### Expression DNA

Expression DNA defines communication style:

- **Sentence Structure**: Short and direct vs. elaborate
- **Vocabulary**: Technical jargon vs. simple language
- **Rhythm**: Fast-paced vs. measured
- **Humor**: Dry wit vs. slapstick
- **Certainty**: Confident vs. hedged statements

## Tips for Best Results

1. **Write descriptive text**: More detail = better analysis
2. **Define clear eras**: Helps Nuwa understand character evolution
3. **Review suggestions carefully**: Use your judgment
4. **Iterate**: Run multiple analyses as you develop your character

## Source Policy Options

- **Local Only**: Analysis based only on your character data
- **Local + Web**: Incorporates external research (books, articles)

## Privacy

Nuwa analysis is private by default. Only you can see the suggestions unless you publish your character.
