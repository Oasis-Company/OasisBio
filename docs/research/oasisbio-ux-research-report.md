### 1.2 启发式评估 — 发现汇总

| # | Nielsen 原则 | 评级 | 代表问题 |
|---|-------------|------|---------|
| H1 | 系统状态可见性 | ⚠️ 中 | Wizard Step 4-6 无保存状态；Nuwa 运行无实时进度；Dashboard 数据加载用 Spinner 而非骨架屏 |
| H2 | 系统与现实对应 | ✅ 高 | 身份/能力/世界观概念与用户心智模型高度吻合 |
| H3 | 用户控制权 | ⚠️ 中 | 创建向导 Step 4-6 按钮不可点击；无法中途保存草稿；Nuwa apply 后不可撤销 |
| H4 | 一致性与标准 | ⚠️ 中 | Dashboard 用 `bg-muted`，落地页用 `bg-black`；表单验证风格不统一 |
| H5 | 错误预防 | ❌ 低 | 身份模式下拉缺少 `worldbound`（落地页展示 6 种，向导只支持 5 种）；Slug 无重复校验 |
| H6 | 识别而非回忆 | ⚠️ 中 | 创建向导无步骤摘要；编辑器无面包屑；Nuwa 输出无结构化说明 |
| H7 | 灵活性与效率 | ⚠️ 中 | 高级用户无法跳过向导；Nuwa 无批量操作 |
| H8 | 审美与极简设计 | ✅ 高 | 瑞士网格系统清晰；OKLCH 色域专业；动效克制优雅 |
| H9 | 帮助识别错误 | ❌ 低 | OTP 失败仅显示"Invalid or expired"；无具体错误码；无邮件投递失败处理 |
| H10 | 帮助与文档 | ⚠️ 中 | Tooltip 系统刚上线（22 测试用例），但使用率极低；docs/ 文档与代码存在偏差 |

### 1.3 关键用户流程走查

#### 流程 A：注册 → 创建 → 发布（核心完成路径）

```
[OTP 发送成功]
    ↓
[仪表盘骨架屏 1.8s]
    ↓
[点击 "Create New OasisBio"]
    ↓
[6步向导 Step1：Identity ✅]
  填写标题、标语、身份模式、描述...
    ↓
[Next → Step2：Era ⚠]
  "Add Era" 按钮点击后无响应（无 API 调用，无状态更新）
    ↓
[Next → Step3：Abilities ⚠]
  同样问题，"Add Ability" 按钮是纯 UI 占位
    ↓
[Next → Step4-6 ❌]
  仅显示静态内容，无实际保存逻辑
    ↓
[Submit]
  仅基础信息被 POST，Era/Ability 数据丢失
    ↓
[跳转编辑器]
  用户需要在编辑器中重新补充 Era/Ability...
```

**问题识别**：
- 痛点 P1：向导流程**制造虚假完成感**——用户以为完成了所有步骤，实际上只有 Step 1 数据被保存
- 痛点 P2：用户被迫进入**二次填充循环**——完成向导后还需要去多个子页面补充数据
- 痛点 P3：**数据丢失风险**——用户没有保存草稿的能力

#### 流程 B：Nuwa AI 深化工作流

```
[编辑器 → Nuwa Tab]
    ↓
[工作台加载（35KB page.tsx）]
    ↓
[用户配置参数并运行]
    ↓
[轮询 /api/nuwa/runs/[runId]]
    ↓
[结果返回：suggestion 列表]
    ↓
[逐个审阅 suggestion → Apply/Reject]
    ↓
[状态更新]
```

**问题识别**：
- 痛点 P4：Nuwa 是**黑盒操作**——用户不知道 LLM 在分析什么，不理解 suggestion 的价值
- 痛点 P5：**批量操作缺失**——10+ suggestion 需逐个处理，效率低
- 痛点 P6：suggestion 被 apply 后**无撤销机制**，而 Manifesto 强调"数字身份"的不可逆性
- 痛点 P7：认知框架输出（mentalModels/heuristics 等）没有**可视化解释**，用户面对 markdown 感到困惑

#### 流程 C：公开档案分享

```
[发布角色]
    ↓
[复制 /bio/[slug] 链接]
    ↓
[分享给朋友/社区]
    ↓
[第三方访问公开页]
```

**问题识别**：
- 痛点 P8：公开页缺乏**社交分享优化**（OG 标签虽有但不完整，Twitter Card 尺寸不对）
- 痛点 P9：公开页没有**分享引导**（"认识一下这个角色" 缺少 CTA）

## 💡 阶段三：重构洞察

### 洞察 1：「完成感陷阱」— 向导的虚假承诺

**现象**：6 步向导给了用户"全部完成"的预期，但 Step 4-6 是空按钮，Step 2-3 只有 UI 占位。

**根因**：向导被设计为"线性引导"，但数据保存逻辑只在 Step 1 和最终的 Submit 中实现，中间步骤是纯 UI Mock。

**影响**：
- 用户在 Step 4-6 点击 Next 后，以为数据已保存，实际上什么都没存
- 用户在编辑器中需要"二次补充"，造成重复劳动和挫败感
- 这个"完成感陷阱"是**流失率最高**的节点之一

**重构建议**：
```
方案 A（快速）：将向导改为"3步核心 + 可选扩展"
  - Step1: Identity（必填，核心数据）
  - Step2: Era + Ability（必填，基础能力）
  - Step3: Preview + Publish（必填，发布）
  → 扩展内容（World/DCOS/Reference/Model）移至编辑器子页面

方案 B（完整）：实现向导内实时保存
  - 每个步骤切换时自动 POST 部分数据到草稿端点
  - 步骤切换时显示 "Saved ✓" 状态
  - Step 4-6 接入真实 API（仓储创建/模型上传/发布预览）
```

### 洞察 2：「身份深度 vs. 工具感」— Nuwa 需要翻译层

**现象**：Nuwa AI 输出的认知框架（mentalModels/decisionHeuristics/expressionDNA）技术含量很高，但普通用户看到 markdown 格式的 suggestion 卡片时，无法理解这些内容对角色塑造有何价值。

**根因**：Nuwa 被设计为"认知蒸馏引擎"，但**前端没有将输出翻译成用户语言**。用户得到的是 AI 思考过程，而非角色增值建议。

**影响**：
- 技术型用户可能理解价值，但会质疑输出的可操作性
- 创意型用户会因为"看不懂"而放弃使用 Nuwa

**重构建议**：
```
Nuwa 工作台重构：三层翻译层
  Layer 1：「这意味着什么」— 每个 suggestion 附带一句话解读
           "AI 分析：你角色的决策风格倾向于风险规避，这在面对道德困境时会表现为..."
  Layer 2：「推荐行动」— 将 suggestion 翻译为具体操作
           "建议：为这个角色添加一条 DCOS 规则：'在不确定时选择最小伤害路径'"
  Layer 3：「角色一致性分数」— 量化输出质量
           "当前角色一致性：87%（建议达到 90%+ 后再发布）"
```

### 洞察 3：「探索即体验」— Explore 页是产品门面

**现象**：Explore 页是未登录用户的主要入口，但当前只加载了 `ExploreContentWrapper` 组件，内容为空。

**根因**：
- `/explore/page.tsx` 只有 11 行，没有搜索、分页、筛选
- Strategy Plan 将其列为 P0 待完成项

**影响**：
- 新用户点击落地页 CTA 后无法预览"已有内容"，降低注册动机
- 竞品（WorldAnvil、NovelAI）都有丰富的探索页

**重构建议**：
```
Explore 页功能矩阵（优先级排序）
  P0: 公开角色卡片网格（标题+标语+身份模式+发布时间）
  P0: 搜索栏（按标题/tag/身份模式过滤）
  P0: 分页（12个/页，虚拟滚动优化）
  P1: 身份模式筛选器（Real/Fictional/Hybrid/Future/Alternate/Worldbound）
  P1: 排序（最新/最热/随机）
  P2: 用户主页入口（/u/[username]）
```

### 洞察 4：「发布即身份」— 公开页需要社交化

**现象**：用户发布角色后得到 `/bio/[slug]` 链接，但链接本身没有任何社交引导。

**根因**：当前设计将"分享"视为结果，而非功能。

**重构建议**：
```
发布完成页新增：
  - "分享到" 快捷按钮（Twitter/X、微信、复制链接）
  - 预览 QR Code（移动端扫码查看）
  - 嵌入代码（其他网站可嵌入角色卡片）
  - 公开档案增强：添加"关于这个人"段落（用户可自定义）
```

### 洞察 5：「身份模式的认知鸿沟」

**现象**：落地页展示了 6 种身份模式（Real/Fictional/Hybrid/Future/Alternate/Worldbound），但：
- 创建向导下拉框只有 5 种（缺少 Worldbound）
- 编辑器下拉框也只有 5 种
- 用户不知道自己应该选哪种

**根因**：身份模式是产品核心概念，但**缺乏引导性解释**。

**重构建议**：
```
身份模式选择器升级：
  - 每个选项附带 tooltip 说明（"这个角色只存在于特定虚构世界中"）
  - 示例角色卡片（Real 模式下展示一个真实人物示例，Worldbound 展示一个虚构角色示例）
  - 首次选择时显示引导动画
```

## ⚠️ 研究局限性

1. **无真实用户数据**：以上分析基于代码审查和竞品推断，需访谈验证
2. **中文 vs 英文用户体验差异**：Manifesto 强调数字永生，对中英文用户吸引力可能不同
3. **Nuwa 是新功能**：用户对 AI 辅助创建角色的接受度无法从代码中推断
4. **移动端覆盖不足**：代码中移动端响应式实现有限，需专项测试
